# 工作流自動化

> 將重複性任務編排成自動化流程，減少人工介入、提高效率和一致性。

## 核心

工作流自動化是將手動操作轉為系統化、可重複執行的流程。從簡單的腳本到複雜的多 Agent 編排系統。

### 層次
- **任務自動化** — 單一操作自動化（cron、腳本）
- **流程自動化** — 多步驟任務串接（n8n、Zapier）
- **Agent 編排** — AI Agent 自主規劃和執行（CrewAI、LangGraph）

### 框架
- **n8n** — 開源工作流自動化平台
- **Zapier / Make** — 雲端自動化服務
- **Airflow** — 資料工程工作流
- **LangGraph** — LLM Agent 工作流

## 與 AI Agent 的關係

AI Agent 是工作流自動化的進化：
- **從規則到推理**：傳統流程靠固定規則，Agent 靠推理適應變化
- **從管線到圖譜**：Agent 工作流不再線性，而是動態圖譜
- **從觸發到自主**：Agent 可主動發起和優化工作流
