# MoneyPrinterTurbo

- **Repo**: [harry0703/MoneyPrinterTurbo](https://github.com/harry0703/MoneyPrinterTurbo)
- **Stars**: 62,027 ⭐
- **Language**: Python
- **Created**: 2024-03-11

> 利用 AI 大模型，一鍵生成高清短視頻。提供主題或關鍵詞，自動生成文案、素材、字幕、配樂，合成完整短影音。

## 核心特點

- **全自動流程**：從主題到成片一鍵完成
- **多模型支持**：OpenAI、DeepSeek、Moonshot、Gemini、Ollama 等
- **多尺寸輸出**：9:16 竖屏 / 16:9 横屏
- **語音合成**：Edge TTS + Azure TTS，支持中英文
- **字幕與配樂**：自動生成可自訂樣式的字幕，搭配背景音樂
- **Web UI + API**：Streamlit 界面 + FastAPI，部署靈活
