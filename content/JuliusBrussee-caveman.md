## 簡介

Claude Code / Codex 的 plugin，讓 AI 用「穴居人語」回答，砍掉約 75% 的 output tokens 但保持完整技術準確性。支援 Lite / Full / Ultra / 文言文 四種強度等級。還附帶 caveman-shrink MCP middleware 壓縮 input tokens。

## 特色

- 75% output token 縮減，100% 技術準確度保留
- 四種強度：Lite / Full / Ultra / 文言文
- 一鍵安裝，自動偵測 30+ agent harness
- caveman-shrink MCP middleware 壓縮 ~46% input tokens
- 附帶 terse commits、one-line reviews、lifetime stats
