## 簡介

一個 CLI 統管 Google Workspace 所有 API（Drive、Gmail、Calendar、Sheets、Docs、Chat、Admin 等）。動態從 Google Discovery Service 建構命令介面，Google 新增 API 自動支援。內建 40+ AI agent skills，每個回應都是結構化 JSON。

## 特色

- 動態命令介面，自動追蹤 Google Discovery Service
- 40+ AI agent skills 內建
- 所有回應結構化 JSON
- 支援 OAuth、Service Account、CI 等多種認證
- Rust 撰寫，預編譯二進位檔 + npm / Homebrew 安裝

## 為什麼值得關注

Google Workspace CLI — one command-line tool for Drive, Gmail, Calendar, Sheets, Docs, Chat, Admin, and more. Dynamically built from Google Discovery Service. Includes AI agent skills.
