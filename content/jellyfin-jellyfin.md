# Jellyfin

⭐ 52K+｜C#｜2026-05-27

> The Free Software Media System - Server Backend & API

## 摘要

Jellyfin 是開源的媒體管理與串流系統，作為專有軟體 Emby 和 Plex 的替代方案。從 Emby 3.5.2 fork 而來，移植到 .NET 平台以支援跨平台運行。無付費授權、無隱藏議程，完全由社群驅動。

## 重點

- **完全免費開源**：GPL 2.0 授權，無付費牆、無高級功能限制
- **自架串流媒體**：從自家伺服器串流媒體到各種終端裝置
- **跨平台**：基於 .NET，支援 Docker、Linux、Windows、macOS
- **Plex/Emby 替代**：功能匹敵但開放透明
- **社群活躍**：Matrix 聊天、多語翻譯齊全
