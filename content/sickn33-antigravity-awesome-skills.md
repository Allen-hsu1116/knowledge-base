## 簡介

Antigravity Awesome Skills 是一個可安裝的 GitHub 技能庫和 npm installer，提供 1,443+ 個結構化的 `SKILL.md` playbook。不再只是收集零散的 prompt 片段，而是提供可搜尋、可安裝的技能目錄，包含 bundles、workflows 和 plugin-safe distribution。

## 主要特色

- **1,443+ Skills**：涵蓋開發、測試、安全、基礎設施、產品和行銷等領域
- **多平台支援**：Claude Code、Cursor、Codex CLI、Gemini CLI、Antigravity、Kiro、OpenCode、Copilot
- **一鍵安裝**：`npx antigravity-awesome-skills` 指令即可安裝
- **Bundle 系統**：預組合的技能包，如前端開發、安全審查等
- **Workflow 驅動**：多步驟技能執行流程，適合規劃、編碼、除錯等場景
- **Plugin 架構**：針對 Claude Code 和 Codex 的 marketplace-style 安裝

## 安裝

```bash
npx antigravity-awesome-skills
# 或指定平台
npx antigravity-awesome-skills --claude
npx antigravity-awesome-skills --cursor
npx antigravity-awesome-skills --gemini
```
