# Plausible Analytics

> Open source, privacy-first web analytics — lightweight, cookie-free Google Analytics alternative

**Repo:** <https://github.com/plausible/analytics>
**Stars:** ⭐ 25,755
**Language:** Elixir
**Created:** 2018-12-04

## 一句話

Plausible 是 GDPR/CCPA 合規的隱私優先網站分析工具，不使用 cookie、不儲存個人資料，用輕量腳本取代 Google Analytics。

## 核心概念

Plausible 的核心理念是**隱私優先的分析**——測量流量而非個人，用訂閱制商業模式取代廣告科技跟蹤。

### 特色

- **無 Cookie、合規**：完全 GDPR / CCPA / PECR 合規，無需同意橫幅
- **輕量腳本**：小於 1KB 的追蹤腳本，加速網站載入
- **簡潔儀表板**：所有關鍵指標一目了然，不需培訓
- **目標追蹤**：自訂事件、轉換、漏斗分析
- **即時洞察**：即時流量監控
- **API 與整合**：Stats API / CSV 匯出 / Google Search Console

### 部署方式

- **Cloud**：官方代管服務，2 分鐘設定，EU 託管
- **Community Edition (CE)**：自架版本，AGPLv3 授權，每年兩次長期發布

### 技術棧

- Backend：Elixir + Phoenix
- Database：PostgreSQL + ClickHouse
- Frontend：React + TailwindCSS
