# Agent Harness 優化

> 系統化提升 AI coding agent 的效能：token 效率、記憶管理、安全驗證、持續學習。

## 核心

Agent Harness 是 AI Agent 的執行環境和控制框架。Harness 優化是讓 Agent 從「能用」變成「好用」的關鍵工程。

### 四大優化維度
1. **Token 優化** — 減少不必要的 context 消耗（壓縮、快取、摘要）
2. **記憶管理** — 跨 session 保持上下文（持久化記憶、知識庫）
3. **安全驗證** — 防止有害操作（沙箱、權限控制、稽核軌跡）
4. **持續學習** — Agent 從經驗中改進（self-correction、skill 累積）

### 跨 Harness 策略
- 在 Claude Code、Codex、Cursor 等 7+ 工具間統一優化
- 抽象出共通的 skill 格式、記憶介面、安全原則
