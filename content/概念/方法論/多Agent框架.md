# 多 Agent 框架

> 多 Agent 框架將不同角色分配給多個 LLM Agent，形成協作實體處理複雜任務，如模擬軟體公司組織架構或角色分工的專案團隊。

## 核心內容

多 Agent 框架的核心思想是將複雜任務分解為多個子角色，每個角色由獨立的 LLM Agent 承擔，透過協作機制完成整體目標。這模擬了真實組織中的分工模式：產品經理定義需求、工程師撰寫程式碼、測試工程師驗證品質，每個 Agent 專注於自身職責。

MetaGPT 是代表性框架之一，它模擬軟體公司的完整組織架構，從產品經理到架構師再到工程師，各角色按標準化 SOP 協作完成軟體開發。CrewAI 則以更輕量的方式定義角色、目標與任務，讓多個 Agent 以任務為導向協作。

多 Agent 框架的優勢在於：每個 Agent 的 prompt 與 context 更聚焦（不需一個 Agent 包辦所有事），角色間的產出可互相驗證，且可以為不同角色選擇不同模型（如規劃用強模型、執行用快模型）。

## 關鍵要素

- **角色定義**：每個 Agent 有明確角色、目標與職責邊界
- **協作機制**：Agent 間透過訊息傳遞、任務交接等方式協作
- **SOP 流程**：標準化操作流程確保 Agent 間產出可銜接
- **異構模型選擇**：不同角色可使用不同 LLM，兼顧品質與成本
- **MetaGPT / CrewAI**：模擬組織架構與角色分工的代表性框架
