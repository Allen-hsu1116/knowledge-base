# Agent 交易

> ⭐— · AI Agent 在金融交易領域的應用：自動化策略執行、多 Agent 協作和風險管理。

## 核心內容

Agent 交易是 AI Agent 和量化交易的交集。多 Agent 系統讓研究 Agent 分析市場、交易 Agent 執行策略、風險 Agent 監控暴露，自動完成從研究到交易的整個流程。

相關專案包括 TradingAgents（多 Agent 交易）、AI-Trader 和 Vibe Trading。
