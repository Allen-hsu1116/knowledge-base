# Computer Use Agent

> 能操作桌面應用和瀏覽器的 AI Agent，模擬人類的鍵盤滑鼠操作。

## 核心內容

Computer Use Agent 是 AI Agent 的進階形態，能直接操控圖形化介面——點擊按鈕、填寫表單、切換視窗。不同於只能操作 API 或 CLI 的 Agent，Computer Use Agent 能像人類一樣使用任何桌面軟體。

相關專案如 AIRI、CUA 都實作了不同取向的 Computer Use Agent。
