# Copilot 生態系

> Copilot 生態系是 GitHub Copilot 的社群資源生態，包含 Agent、Skill、Hook、Workflow、Plugin，由 GitHub 官方維護策展。

## 核心內容

Copilot 生態系是圍繞 GitHub Copilot 建立的延伸資源體系，讓 Copilot 從單純的程式碼補全工具進化為可擴充的 AI coding 平台。生態系包含多種元件類型，各有不同用途但共同擴展 Copilot 的能力邊界。

Agent 是具備自主規劃與執行能力的 Copilot 模式，能自主分解任務、呼叫工具、迭代完成目標。Skill 是結構化的操作指令，讓 Copilot 以明確步驟執行特定任務。Hook 在特定事件觸發時自動執行預定義動作。Workflow 定義多步驟流程，串聯多個操作完成複雜任務。Plugin 則是封裝特定功能的可安裝套件。

這些元件由 GitHub 官方維護策展，確保品質與相容性。生態系的成長讓 Copilot 不再局限於程式碼補全，而是成為可客製化的 AI 開發助手。

## 關鍵要素

- **Agent**：自主規劃與執行的 Copilot 模式，能分解任務並迭代完成
- **Skill**：結構化操作指令，讓 Copilot 以明確步驟執行特定任務
- **Hook**：事件驅動的自動執行，在觸發條件下自動運作
- **Workflow**：多步驟流程定義，串聯操作完成複雜任務
- **Plugin**：封裝特定功能的可安裝套件，擴展 Copilot 能力
- **官方策展**：GitHub 官方維護品質與相容性
