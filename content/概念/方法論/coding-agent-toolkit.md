# Coding Agent 工具包

> ⭐— · 為 coding agent 提供搜尋、導航和程式碼理解能力的工具集合。

## 核心內容

Coding Agent 工具包讓終端機 AI 助手具備程式碼搜尋、導航、理解和操作能力。例如 FFF 提供超快檔案搜尋，是 Neovim 和 coding agent 的底層搜尋引擎。
