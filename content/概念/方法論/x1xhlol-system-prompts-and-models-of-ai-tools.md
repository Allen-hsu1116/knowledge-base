# System Prompts and Models of AI Tools

> ⭐139.2k · 全面收集 AI 工具的系統提示詞與內部模型——涵蓋 Cursor、Devin、Windsurf、Claude Code、Replit、Perplexity 等 20+ 主流 AI coding 助手。

## 快速導航

- 🧠 [[CLAUDE-md|CLAUDE.md]] — AI 編碼助理的行為規範格式
- 🔌 [[AI-Skills|AI Skills]] — 結構化操作指令格式
- 🛡 [[prompt-security|Prompt 安全與越獄]] — 系統提示詞的安全風險

## 是什麼

這是目前 GitHub 上最大規模的 AI 工具系統提示詞（system prompts）與內部工具集合。作者持續從各大 AI coding 助手（Cursor、Devin、Windsurf、Claude Code、Augment Code、Lovable、Manus、Replit 等）逆向提取完整的系統提示詞，並公開收錄。對理解 AI 工具如何被指令、各家工具的策略差異、以及 prompt engineering 實務有極高參考價值。

專案不只收集提示詞，也收錄了開源的內部模型和工具定義，讓開發者能深入了解這些 AI 產品背後的運作邏輯。

## 核心特色

- **20+ 主流 AI 工具**：涵蓋 Cursor、Devin、Windsurf、Claude Code、Augment Code、Replit、Perplexity、Lovable、Manus 等
- **完整系統提示詞**：不是摘要，是完整的系統提示詞原文，可逐行研究
- **持續更新**：社群驅動，AI 工具更新時同步跟進
- **開源免費**：GPL-3.0 授權，可自由使用和分享
- **安全研究價值**：對 AI 安全研究者和 prompt engineering 實踐者，這是了解攻防的第一手素材

## 怎麼用

```bash
# 複製專案
git clone https://github.com/x1xhlol/system-prompts-and-models-of-ai-tools.git

# 瀏覽各工具的提示詞
cd system-prompts-and-models-of-ai-tools
ls -la  # 按工具名稱分類的目錄

# 範例：查看 Cursor 的系統提示詞
cat cursor/system_prompt.md
```

直接在 GitHub 上瀏覽也可以，每個工具的提示詞都有獨立的 Markdown 檔案。
