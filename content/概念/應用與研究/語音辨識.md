# 語音辨識

> 將語音轉為文字（ASR）和將文字轉為語音（TTS）的技術，是 AI 多模態應用的關鍵組件。

## 核心內容

語音辨識是將語音訊號轉換為文字（ASR，Automatic Speech Recognition）的技術，語音合成則是反向將文字轉為語音（TTS，Text-to-Speech）。兩者合稱語音技術，是 AI 多模態應用的關鍵組件——讓機器能「聽」和「說」。

ASR 技術近年因 Whisper 等開源模型大幅普及，支援 100+ 語言、能在噪音環境和低音質條件下保持魯棒性。TTS 技術則從傳統拼接式合成進化到神經網路合成，語音克隆只需少量樣本即可複製特定說話人的聲音，情感控制和即時串流也成為標準能力。

在 AI Agent 應用中，語音技術構成完整的語音互動迴路：ASR 將使用者語音轉為文字 → LLM 理解並生成回應 → TTS 將回應轉為語音輸出。這個迴路驅動了語音助手、會議紀錄自動轉錄、AI 影視多角色旁白、簡報語音旁白等應用場景。

## 關鍵要素

- **多語言支援**：Whisper 支援 100+ 語言，現代 TTS 模型也支援跨語言合成
- **語音克隆**：少量樣本即可複製特定說話人聲音，實現個人化語音
- **即時串流**：低延遲的串流辨識和合成，適合即時對話場景
- **魯棒性**：在噪音環境、口音、低音質條件下保持辨識能力
- **情感控制**：調整語速、語調、情感，讓合成語音更自然
- **強制對齊**：精確到詞級別的時間戳，支援字幕同步和唇形對齊

## 各框架的做法

- **Whisper** → OpenAI 開源 ASR 模型，多語言、魯棒性強，是語音辨識的基準模型
  👉 詳見 [[Whisper]]
- **VibeVoice** → 微軟多語言語音 AI，支援長語音辨識和串流 TTS
  👉 詳見 [[microsoft-VibeVoice\|VibeVoice]]
- **VoxCPM** → Tokenizer-Free 語音合成，支援語音克隆和 30 語言
  👉 詳見 [[OpenBMB-VoxCPM\|VoxCPM]]
- **Voicebox** → AI 語音工作室，整合 7 個 TTS 引擎、語音克隆和聽寫功能
  👉 詳見 [[jamiepine-voicebox\|Voicebox]]
- **MOSS-TTS** → 多語言語音合成與語音克隆開源模型
  👉 詳見 [[OpenMOSS-MOSS-TTS\|MOSS-TTS]]
- **Supertonic** → 邊緣裝置 TTS，ONNX Runtime 推論，CPU 即可即時合成
  👉 詳見 [[supertone-inc-supertonic\|Supertonic]]
- **FluidVoice** → macOS 聽寫應用，on-device STT + Fluid Intelligence 本地 AI 增強
  👉 詳見 [[altic-dev-FluidVoice\|FluidVoice]]

- **VoiceStudio** → 整合 16 個 TTS、11 個 ASR、語音克隆、配音、OpenAI API 與 MCP 的本地平台
  👉 詳見 [[debpalash-VoiceStudio\|VoiceStudio]]
