# 資料分析

> 從原始資料中提取洞見、模式和結論的方法與工具，是金融預測、商業決策和科學研究的基礎。

## 核心內容

資料分析是從原始資料中提取洞見、模式和結論的系統化方法。在 AI 時代，資料分析的範疇已從傳統的統計分析擴展到涵蓋機器學習特徵工程、自動化報告生成和 AI 驅動的洞見發現。它是金融預測、商業決策和科學研究的共同基礎。

資料分析的典型流程包含：資料收集（從 API、資料庫、爬蟲取得原始資料）、資料清洗（處理缺失值、異常值、格式不一致）、探索性分析（統計摘要、分佈檢視、相關性分析）、特徵工程（從原始資料提取有意義的特徵）、建模與分析（統計模型、機器學習、AI Agent）和視覺化呈現（圖表、儀表板、報告）。

AI Agent 正在改變資料分析的工作方式。傳統流程需要分析師手動執行每個步驟，而 AI Agent 能自主完成資料探索、假設生成、分析執行和報告撰寫的閉環。LLM 讓 Agent 能用自然語言描述分析結果，RAG 讓 Agent 能結合外部知識做更深入的解讀，MCP 讓 Agent 能連接各種資料源和分析工具。

## 關鍵要素

- **資料清洗與預處理** — 處理缺失值、異常值和格式不一致，確保分析品質
- **探索性分析** — 統計摘要、分佈檢視、相關性分析，建立對資料的直覺理解
- **特徵工程** — 從原始資料提取有意義的特徵，為建模提供高品質輸入
- **視覺化呈現** — 圖表、儀表板和互動式報告，讓洞見易於理解和傳達
- **自動化管線** — 從擷取到分析的端到端自動化，減少人工介入
- **AI 驅動洞見** — LLM + Agent 自主發現模式、生成假設和解讀結果
