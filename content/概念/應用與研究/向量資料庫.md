# 向量資料庫

> ⭐27,900 · 儲存和檢索向量嵌入（embeddings）的專用資料庫，是 [[rag|RAG]] 和語意搜尋的基礎設施。

## 快速導航

- 📚 **RAG** → [[rag]]（向量資料庫是 RAG 管線的核心儲存層）
- 🤖 **AI Agent** → [[AI-Agent]]（Agent 的記憶和知識檢索依賴向量搜尋）
- 🧠 **知識庫** → [[llm-knowledge-base]]（知識庫系統可搭配向量搜尋做語意檢索）
- 🕸️ **知識圖譜** → [[Knowledge-Graph]]（知識圖譜 + 向量搜尋 = 混合檢索）

## 是什麼

向量資料庫專門用來儲存高維向量（embeddings），並提供快速的近似最近鄰搜尋（ANN）。在 LLM 應用中，文字先轉成向量，再透過向量資料庫做語意搜尋。它是 [[rag|RAG]] 和語意搜尋的基礎設施，所有需要「根據意義而非關鍵字」來找資料的場景都會用到。

## 核心特色

| 概念 | 說明 |
|------|------|
| Embedding | 將文字/圖片轉成固定維度的向量表示 |
| ANN 搜尋 | 近似最近鄰搜尋，犧牲少量精度換取大幅加速 |
| 索引演算法 | HNSW、IVF、PQ 等加速搜尋的資料結構 |
| 距離度量 | cosine similarity、L2、inner product |

## 怎麼用

以 ChromaDB 為例（最簡單的入門選擇）：

```bash
pip install chromadb
```

```python
import chromadb

client = chromadb.PersistentClient(path="./chroma_db")
collection = client.create_collection("my_docs")

# 新增文件
collection.add(
    documents=["這是第一份文件", "這是第二份文件"],
    ids=["doc1", "doc2"]
)

# 語意搜尋
results = collection.query(
    query_texts=["搜尋相關內容"],
    n_results=2
)
```

大規模場景用 Milvus：

```python
from pymilvus import connections, Collection

connections.connect("default", host="localhost", port="19530")
collection = Collection("my_collection")
results = collection.search(
    data=query_vector,
    anns_field="embedding",
    param={"metric_type": "COSINE", "params": {"nprobe": 10}},
    limit=5
)
```

## 在 RAG 中的角色

```
文件 → 切塊 → Embedding → 存入向量資料庫
                                    ↓
查詢 → Embedding → 語意搜尋 → 取得相關文件 → 餵給 LLM
```

向量資料庫是 [[rag|RAG]] 管線的核心儲存層。

## 與知識庫的關係

我們的知識庫系統（raw→wiki→lint）不完全依賴向量搜尋，而是用結構化的 wiki 頁面 + 概念索引。但向量搜尋可作為補充：
- 在 wiki 頁面內做語意搜尋
- 跨頁面的相關性排序
- [[MemPalace-mempalace|MemPalace]] 用 ChromaDB 做 Drawer 層的語意搜尋
