# 免費軟體

> 開源或免費的軟體工具，降低技術門檻、促進普及。

## 核心內容

免費軟體（Free Software）指可自由使用、修改和分發的軟體。在自由軟體運動的語境中，「free」指的是自由（liberty）而非價格——使用者有研究、修改、散布程式的自由。但在實務層面，開源和免費軟體大幅降低了技術門檻，讓個人開發者和小團隊能用上過去只有大企業才負擔得起的工具。

開源生態系提供了從開發、設計到日常使用的完整工具鏈。開發者有 VS Code、Git、Docker 等免費工具；設計師有 Penpot（開源 Figma 替代）、GIMP；生產力有 Plane（Jira 替代）、Twenty（CRM 替代）、ERPNext（ERP 替代）。這些工具的品質已經足以與商業軟體競爭，甚至在某些場景中超越。

AI 時代進一步推動了免費軟體的普及。Ollama 讓任何人都能在本地免費運行 LLM，Open WebUI 提供了免費的 ChatGPT 替代介面，大量 Agent Skills 和 MCP Server 以開源形式發布。免費軟體不再是「妥協方案」，而是許多場景下的首選。

策展列表（如 Awesome Free Apps）系統性地整理了各領域的免費軟體資源，讓使用者能快速找到替代商業軟體的開源方案。

## 關鍵要素

- **自由使用** — 不受授權費限制，個人和企業均可免費使用
- **可修改性** — 開源授權允許檢視和修改原始碼，適應特殊需求
- **社群驅動** — 由全球開發者社群維護，持續更新和改進
- **替代商業軟體** — 開源方案已能替代大部分商業軟體，品質持續提升
- **策展列表** — Awesome 系列等策展列表系統化整理免費軟體資源
- **AI 工具普及** — Ollama、Open WebUI 等讓 AI 工具也能免費使用
