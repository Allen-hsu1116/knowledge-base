## 是什麼

網頁爬蟲（Web Crawling）是系統化地瀏覽和收集網頁資料的技術。與 [[網頁爬蟲|網頁爬取（Scraping）]] 的差異：爬蟲強調系統化遍歷（如 Googlebot 爬遍整個網站），爬取強調資料提取（如 Crawl4AI 把網頁轉成乾淨 Markdown）。在 AI 時代，爬蟲和爬取的界線越來越模糊——AI Agent 需要同時遍歷和提取。

## 核心特色

- **系統化遍歷**：從種子 URL 開始，沿連結爬遍目標網站
- **遵守規則**：robots.txt、rate limiting、禮貌爬取
- **去重機制**：避免重複訪問同一頁面
- **JavaScript 渲染**：現代網頁需要瀏覽器引擎才能取得完整內容
- **反偵測**：User-Agent 輪換、代理池、指紋偽裝

## 爬蟲 vs 爬取

| | 爬蟲 (Crawling) | 爬取 (Scraping) |
|---|---|---|
| 目的 | 發現和索引頁面 | 提取特定資料 |
| 範圍 | 廣泛、系統化 | 針對性 |
| 速度 | 大量並行 | 按需 |
| 例子 | Googlebot | Crawl4AI |

## 爬蟲核心流程

1. **種子 URL**：起始點
2. **下載頁面**：HTTP 請求
3. **解析連結**：提取頁面中的 URL
4. **URL 佇列**：待訪問的 URL 佇列
5. **去重**：避免重複訪問
6. **遵守規則**：robots.txt、rate limiting

### 基本爬蟲（Python requests + BeautifulSoup）

```python
import requests
from bs4 import BeautifulSoup
from urllib.parse import urljoin

def crawl(start_url, max_pages=100):
    visited = set()
    queue = [start_url]
    results = []
    
    while queue and len(visited) < max_pages:
        url = queue.pop(0)
        if url in visited:
            continue
        visited.add(url)
        
        resp = requests.get(url, headers={"User-Agent": "MyBot/1.0"})
        soup = BeautifulSoup(resp.text, "html.parser")
        results.append({"url": url, "text": soup.get_text()})
        
        for link in soup.find_all("a", href=True):
            next_url = urljoin(url, link["href"])
            if next_url not in visited:
                queue.append(next_url)
    
    return results
```

## 常見挑戰

| 挑戰 | 說明 | 解法 |
|------|------|------|
| JavaScript 渲染 | 需要 Playwright/Selenium 等瀏覽器引擎 | Crawl4AI 內建瀏覽器 |
| 反爬機制 | CAPTCHA、IP 限制、User-Agent 偵測 | 代理池、指紋偽裝 |
| 網站結構變化 | 選擇器失效 | LLM 抽取、彈性解析 |
| 大規模並行 | 速率控制、代理池管理 | 分散式架構 |
| 法律合規 | robots.txt、著作權、GDPR | 遵守 robots.txt、尊重版權 |

## AI Agent 的爬蟲需求

現代 AI Agent 需要的不只是原始 HTML：
- **乾淨的 Markdown**：[[Crawl4AI|Crawl4AI]]、Jina Reader
- **結構化資料**：JSON-LD、schema.org
- **JavaScript 渲染**：需要瀏覽器引擎
- **多平台**：Twitter、Reddit、YouTube 等（見 [[opencli|OpenCLI]]）
