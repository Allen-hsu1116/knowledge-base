# 網頁爬蟲 (Web Crawling)

> 網頁爬蟲是系統化地瀏覽和收集網頁資料的技術。與 [[web-scraping|網頁爬取 (Scraping)]] 的差異：爬蟲強調系統化遍歷，爬取強調資料提取。

## 爬蟲 vs 爬取

| | 爬蟲 (Crawling) | 爬取 (Scraping) |
|---|---|---|
| 目的 | 發現和索引頁面 | 提取特定資料 |
| 範圍 | 廣泛、系統化 | 針對性 |
| 速度 | 大量並行 | 按需 |
| 例子 | Googlebot | Crawl4AI |

## 爬蟲核心流程

1. **種子 URL**：起始點
2. **下載頁面**：HTTP 請求
3. **解析連結**：提取頁面中的 URL
4. **URL 佇列**：待訪問的 URL 佇列
5. **去重**：避免重複訪問
6. **遵守規則**：robots.txt、rate limiting

## 常見挑戰

| 挑戰 | 說明 |
|------|------|
| JavaScript 渲染 | 需要 Playwright/Selenium 等瀏覽器引擎 |
| 反爬機制 | CAPTCHA、IP 限制、User-Agent 偵測 |
| 網站結構變化 | 選擇器失效 |
| 大規模並行 | 速率控制、代理池管理 |
| 法律合規 | robots.txt、著作權、GDPR |

## AI Agent 的爬蟲需求

現代 AI Agent 需要的不只是原始 HTML：
- **乾淨的 Markdown**：[[Crawl4AI|Crawl4AI]]、Jina Reader
- **結構化資料**：JSON-LD、schema.org
- **JavaScript 渲染**：需要瀏覽器引擎
- **多平台**：Twitter、Reddit、YouTube 等（見 [[opencli|OpenCLI]]）
