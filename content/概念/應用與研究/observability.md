# 可觀測性

> ⭐— · 系統的日誌、指標和追蹤三大支柱，確保系統健康可診斷。

## 核心內容

可觀測性（Observability）是 DevOps 和 SRE 的核心概念，透過監控日誌（Logs）、指標（Metrics）和分佈式追蹤（Traces）來理解系統內部狀態。iii 平台提供 Agent 友善的後端整合能力。
