# 開源商業模式

> 開源軟體的商業化策略：如何讓開源專案持續生存並獲利。

## 核心內容

開源商業模式探討如何以開放原始碼為基礎建立可持續的商業模式。開源不等於免費——維護一個大型開源專案需要全職開發者、基礎設施、社群管理，這些都需要資金。成功的開源專案通常有清晰的商業模式來支撐長期維護，否則最終面臨維護者倦怠或專案荒廢。

最常見的模式是 Open Core：核心功能開源免費，進階功能（企業級權限、SSO、審計日誌、SLA 支援）需付費取得。這種模式讓社群免費使用基礎版本，同時從企業客戶獲取營收。代表性案例包括 GitLab、Plane、n8n 等。

另一種主流模式是 SaaS（開源軟體即服務）：軟體本身開源，但提供託管版本讓使用者免於自行部署的麻煩。使用者付費換取「不用自己架」的便利性，專案方則獲得穩定訂閱收入。此外還有 Marketplace 模式（平台抽佣，如 VS Code 擴充商店）、雙授權（AGPL 開源 + 商業授權付費）、以及諮詢與支援服務等。

近年 AI 領域出現了新的開源商業模式：模型開源但推論服務收費、Agent Skills 市場、MCP Server 生態系等。這些模式結合了開源的社群效應和 AI 服務的變現能力。

## 關鍵要素

- **Open Core** — 核心開源免費，進階企業功能付費，最常見的開源商業模式
- **SaaS 託管** — 軟體開源但提供付費託管版本，使用者付費換取免部署的便利
- **雙授權** — AGPL 等 copyleft 授權開源，商業用途需購買商業授權
- **Marketplace** — 建立生態系市集，從第三方插件或服務中抽佣
- **諮詢與支援** — 開源免費使用，但付費獲得專業支援、客製化和培訓
- **雲端服務綁定** — 軟體開源，但最佳體驗需要搭配特定雲端服務
