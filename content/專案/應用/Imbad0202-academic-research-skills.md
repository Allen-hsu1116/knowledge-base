# Academic Research Skills

> Claude Code 學術研究技能套件，從研究到發表的完整管線。

## 是什麼

Imbad0202/academic-research-skills 是一套 Claude Code 技能組合，涵蓋學術研究全流程：深度研究、論文撰寫、同儕審查、管線編排。

## 核心特色

- **Deep Research** — 13 Agent 研究團隊，蘇格拉底引導模式、PRISMA 系統性回顧、Semantic Scholar API 驗證
- **Academic Paper** — 12 Agent 論文寫作，風格校正、LaTeX 硬化、視覺化、修訂輔導、引用轉換
- **Academic Paper Reviewer** — 7 Agent 多角度同儕審查，0-100 品質評分
- **Academic Pipeline** — 10 階段管線編排器，自適應檢查點、主張驗證、Material Passport

## 怎麼用

```bash
/plugin marketplace add Imbad0202/academic-research-skills
```

- 與 [[nidhinjs-prompt-master|Prompt Master]] 互補：Prompt Master 寫提示，Academic Research Skills 執行學術研究流程
