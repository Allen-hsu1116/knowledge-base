## 是什麼

nidhinjs/prompt-master 是一個 Claude Code skill，自動為任何 AI 工具撰寫精準提示。核心解決的問題：使用者寫模糊提示 → 反覆重試 → 浪費 token 和額度。

## 核心特色

- **7 步結構化管線** — 偵測工具 → 提取 9 維度意圖 → 澄清問題 → 框架路由 → 安全技術 → Token 審計 → 交付
- **9 維度意圖提取** — task、input、output、constraints、context、audience、memory、success criteria、examples
- **20+ 工具設定檔** — Claude、ChatGPT、Gemini、Cursor、Copilot、Midjourney、Sora 等
- **Universal Fingerprint** — 未知工具的自動適配
- **Token 效率審計** — 確保產出的提示本身不浪費 token
- **安全技術** — role assignment、few-shot、XML structure、grounding anchors、memory block

## 怎麼用

作為 Claude Code skill 安裝，啟動後輸入你想要做的事，它會引導你產出精準提示。
