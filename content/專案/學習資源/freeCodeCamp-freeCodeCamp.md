## 是什麼

freeCodeCamp 是一個由捐助者支援的 501(c)(3) 非營利組織運營的開源程式學習平台。它提供完全免費、自主進度的 Full-Stack Web 開發和 Machine Learning 課程，包含數千個互動式程式設計挑戰。社群已幫助超過 100,000 人獲得他們的第一份開發者工作，是全球最具影響力的程式教育平台之一。

freeCodeCamp 的課程體系涵蓋六個開發者認證：響應式網頁設計、JavaScript、前端開發函式庫、Python、關聯式資料庫、後端開發與 API。每個認證需要完成互動課程、工作坊、實驗室、複習和測驗，最後通過考試取得。此外還提供語言認證（A2/B1 開發者英語、A1 專業西班牙語/中文）以及 Foundational C# with Microsoft 認證。

對於 AI 學習者而言，freeCodeCamp 的 Machine Learning 課程和 Python 認證是進入 LLM 領域的良好起點。平台還包含 The Odin Project、Coding Interview Prep、Project Euler 等輔助學習資源，以及擁有數千篇技術文章的出版品和 YouTube 頻道。

## 核心特色

- **完全免費**：所有課程、認證、挑戰全部免費，無需付費解鎖
- **互動式學習**：數千個程式設計挑戰，在瀏覽器中直接編寫和執行程式碼
- **6 個開發者認證**：Web Design → JavaScript → Frontend → Python → Database → Backend
- **Machine Learning 課程**：包含 ML 相關挑戰和專案，進入 AI 領域的起點
- **社群支援**：論壇（forum.freecodecamp.org）、Discord、YouTube 免費課程
- **開源貢獻**：BSD-3-Clause 授權，歡迎社群貢獻課程和程式碼
- **語言認證**：開發者英語 A2/B1、專業西班牙語/中文 A1

## 怎麼用

```bash
# 線上學習（最簡單）
# https://www.freecodecamp.org/learn/

# Clone 原始碼（貢獻或本地開發）
git clone https://github.com/freeCodeCamp/freeCodeCamp.git
cd freeCodeCamp

# 本地開發環境設定
npm install
npm run develop

# 貢獻指南
# https://contribute.freecodecamp.org/
```
