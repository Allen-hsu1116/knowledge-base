# Prompt Engineering Guide

## 快速導航

## 是什麼

Prompt Engineering Guide（DAIR.AI 出品）是網路上最全面、最權威的 Prompt Engineering 學習資源。它從 2022 年底開始累積，涵蓋了從基礎提示技巧到最先進研究論文的完整知識圖譜。無論你是剛入門想理解什麼是 zero-shot prompting，還是研究者在找 Chain-of-Thought 的最新變體，這裡都有。

這個指南不只是文件集合，而是一個結構化的學習路徑。從基礎概念（LLM Settings、Basics of Prompting）到進階技巧（Chain-of-Thought、ReAct、Tree of Thoughts），再到應用場景（Function Calling、Synthetic Data for RAG、Code Generation），最後是風險與對抗性提示（Adversarial Prompting、Factuality、Biases）。每個主題都附有可執行的 Jupyter Notebook 和對應的學術論文。

DAIR.AI 也推出了自節奏的線上課程（DAIR.AI Academy），提供更動手實作的學習體驗。整個指南支援 13 種語言，累計超過 300 萬學習者。

## 核心特色

- **完整技巧覆蓋**：Zero-Shot、Few-Shot、Chain-of-Thought、Self-Consistency、ToT、ReAct、ART、APE、Active-Prompt 等 16+ 種技術
- **論文驅動**：每個技巧都附上原始論文連結，從學術根源理解方法論
- **可執行 Notebook**：Jupyter Notebook 提供可直接跑的程式碼範例
- **模型專區**：ChatGPT、GPT-4、Gemini、LLaMA、Mistral、Code Llama 等主流模型的提示技巧
- **RAG 指南**：獨立的 RAG 章節，涵蓋檢索增強生成的實作方法
- **風險分析**：Adversarial Prompting、Factuality、Biases 三大風險面向的完整分析
- **13 種語言**：英文、簡中、繁中、日文、韓文等多語支援

## 怎麼用

```bash
# 克隆指南到本地
git clone https://github.com/dair-ai/Prompt-Engineering-Guide.git
cd Prompt-Engineering-Guide

# 本地執行網站版（需要 Node.js >= 18 和 pnpm）
pnpm install
pnpm dev
# 開啟 http://localhost:3000/

# 或直接瀏覽線上版
# https://www.promptingguide.ai/
```
