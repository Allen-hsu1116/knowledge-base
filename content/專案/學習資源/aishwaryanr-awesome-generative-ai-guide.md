## 是什麼

Awesome Generative AI Guide 是由 Aishwarya Naresh Reganti 維護的一個綜合性生成式 AI 學習資源庫。它整合了 GenAI 研究更新、面試資源、Jupyter 筆記本和免費課程，旨在成為生成式 AI 領域的「一站式中樞」。資源庫每月更新最佳 GenAI 論文列表，並提供超過 90 門免費 GenAI 課程的索引。

其中最核心的資源是 Applied LLMs Mastery 2024 課程——一個為期 10 週的深度學習之旅，涵蓋 LLM 基礎、Prompt 工程、微調、RAG、LLM 應用構建、評估技術、部署策略等完整主題。此外還提供 Generative AI Genius 課程、AI Evals for Everyone 認證課程，以及 OpenClaw Mastery 認證課程。

資源庫還提供多條學習路線圖：3 天 RAG 路線圖、5 天 LLM 基礎路線圖、5 天 LLM Agents 路線圖，以及 Agents 101 指南和多模態 LLM 入門指南。在 2024 年 2 月建立後，已成為 GenAI 學習者的重要參考資源。

## 核心特色

- **每月最佳 GenAI 論文列表**：持續更新的研究追蹤
- **Applied LLMs Mastery 2024**：10 週完整課程，1000+ 學生參與
- **90+ 免費課程索引**：來自 ETH Zurich、Princeton、Stanford、Huggingface、Google Cloud 等
- **60 道 GenAI 面試題**：含詳細解答
- **多條學習路線圖**：RAG（3 天）、LLM 基礎（5 天）、LLM Agents（5 天）
- **認證課程**：AI Evals for Everyone、OpenClaw Mastery
- **Jupyter 筆記本庫**：GenAI 應用開發的程式碼集合

## 怎麼用

```bash
# 克隆資源庫
git clone https://github.com/aishwaryanr/awesome-generative-ai-guide.git
cd awesome-generative-ai-guide

# 直接在瀏覽器中瀏覽 README.md
# 或使用 Jupyter 開啟筆記本
pip install jupyter
jupyter notebook
```
