## 是什麼

easy-vibe 是 Datawhale 團隊維護的開源 Vibe Coding 入門教程，口號是「會說話就會做應用」。它用三階段學習路徑（初學者 → 全端開發者 → AI-Native 開發者），帶領完全零基礎的人從「用嘴巴描述需求」走到「獨立交付 AI 應用」。

教程基於 MDX + MkDocs 构建，支援 10 種語言（中英日韓法德西阿越），內容包含互動式動畫教學、模擬 IDE 操作、RAG 可視化、終端概念可視化等，讓抽象的技術概念變得看得見、摸得著。

**為誰而做：**
- 完全零基礎的新手——先做專案，再理解原理
- 產品經理 / 創業者——快速驗證想法，低成本建 MVP
- 學生——培養 AI 時代的實戰技能
- 初級開發者——學會從想法到上線的完整路徑
- 中高級開發者——升級 AI 協作工作流

## 核心特色

- **三階段學習路徑** — Stage 1（初學者：用 AI 做出第一個產品原型）→ Stage 2（全端開發：獨立交付現代 Web 應用）→ Stage 3（AI-Native：進階 Claude Code + Agent 工作流），從零基礎到獨立交付 AI 應用
- **10 種語言支援** — 中英日韓法德西阿越，Stage 1 和 Stage 2 已全面覆蓋所有 10 種語言
- **互動式動畫教學** — 新手友善學習地圖、沉浸式模擬編碼（虛擬滑鼠引導）、AI 原理動畫解釋、互動式 RAG 資料流視覺化、終端概念視覺化
- **附錄知識庫** — 9 大知識領域、80+ 互動主題，涵蓋電腦基礎、前後端基礎、基礎設施、AI 原理、工程實踐等
- **Vibe Stories** — 真實使用者故事（鄉村小學老師、大學生、高中 IT 老師、卡車司機），展示如何用 AI 做出真實產品

**現代方式（AI IDE）**——在 Cursor / Trae / VS Code 的聊天視窗輸入：

```text

```

**傳統方式**：

```bash
git clone https://github.com/datawhalechina/easy-vibe.git
cd easy-vibe
npm install
npm run dev
# 打開 http://localhost:3000
```

| 維度 | easy-vibe | Cursor | Bolt.new | v0.dev |
|------|-----------|--------|----------|--------|
| **定位** | 開源 Vibe Coding 教程 | AI 原生 IDE | 雲端全端生成 | AI UI 生成器 |
| **適合對象** | 零基礎～進階開發者 | 有基礎的開發者 | 想快速做 Demo 的人 | 設計師 / 前端 |
| **學習曲線** | 三階段漸進式 | 中等 | 低 | 低 |
| **輸出** | 知識 + 技能 + 作品 | 完整專案程式碼 | 可部署的 Web App | React 元件 |
| **多語言** | ✅ 10 種語言 | ❌ 英文為主 | ❌ 英文 | ❌ 英文 |
| **開源** | ✅ 完全開源 | ❌ 商業 | ❌ 商業 | ❌ 商業 |
