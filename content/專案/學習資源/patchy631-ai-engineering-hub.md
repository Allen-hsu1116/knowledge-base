# AI Engineering Hub

> ⭐40.3k · 以分級實作專案學習 LLM、RAG、Agent 與模型評估的教學資源庫。

## 快速導航

- [[self-education]] — 延伸概念與相關實作。
- [[rag]] — 使用情境與設計取捨。

## 是什麼

AI Engineering Hub 將 AI 工程主題拆成可探索的專案目錄，涵蓋初學、進階與高階工作流。它是教學與範例集合，不是一個可以用單一啟動命令運行的統一框架。

README 導向 OCR、聊天介面、RAG、MCP、語音與多 Agent 等不同場景。適合先挑一個問題重現，再替換資料與模型；上游使用 production-ready 描述，但不等同所有範例已通過本環境的生產驗證。

## 核心特色

- **分級路徑**：從初學者元件逐步走到複合系統。

- **RAG 範例**：包括基本文件問答、Agentic RAG 與多模態。

- **Agent 場景**：涵蓋研究、文件撰寫與金融分析。

- **評估入口**：包含模型比較、評估與可觀測性範例。

## 怎麼用

### 安裝或取得專案

以下為文件化操作範例；本次收錄沒有在主機安裝或執行此專案。

```bash
git clone https://github.com/patchy631/ai-engineering-hub.git
cd ai-engineering-hub
# 依所選子專案 README 安裝依賴；根目錄沒有統一安裝流程
```

### 使用流程

1. 初學者先閱讀 ai-engineering-roadmap，再選 simple-rag-workflow。
2. 為各子專案建立獨立環境，依其文件設定金鑰與模型。
3. 以固定資料測試回答正確率、延遲與成本，不直接把展示結果當成保證。

### 限制與注意

- README 的專案數量是上游快照，會隨內容變動。
- 金融分析範例是技術教學，不是投資績效證明。
