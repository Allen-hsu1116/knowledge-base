## 是什麼

Hello-Agents 是 Datawhale 社區打造的開源免費系統性智能體教程，目標是填補市面上「AI Native Agent」系統性教學的空白。教程專注於真正以 AI 驅動的智能體——讓你從核心原理出發，理解經典範式，最終親手構建自己的多智能體應用。

整個教程分為五大部分：基礎理論 → 經典範式（ReAct/Plan-and-Solve/Reflection）→ 框架實戰（AutoGen/LangGraph/AgentScope）→ 進階知識（記憶、上下文工程、通信協議）→ 綜合案例與畢業設計。

## 核心特色

- **五大模組循序漸進**：基礎理論 → 經典範式 → 框架實戰 → 進階知識 → 綜合案例與畢業設計
- **從零自研 Agent 框架**：第七章帶你基於 OpenAI 原生 API 從零構建 HelloAgents 框架，培養「用輪子」也「造輪子」的能力
- **覆蓋 Agentic RL 訓練**：第十一章專門講 Agentic RL——從 SFT 到 GRPO 的 LLM 訓練實戰
- **多智能體通信協議**：第十章涵蓋 MCP、A2A、ANP 等最新智能體通信協議
- **社區驅動與持續更新**：有讀者交流群、影片課程、面試題總結等社區精選內容
- **主流框架對比教學**：涵蓋 AutoGen、AgentScope、LangGraph 等框架的橫向對比
- **每章附練習題**：理論結合實踐，每章結尾都有動手練習和思考題
- **畢業設計專案**：最終章提供完整的畢業設計指引，從構想到部署

## 怎麼用

```bash
git clone https://github.com/datawhalechina/hello-agents.git
cd hello-agents
pip install -r requirements.txt
```

教程建議順序學習，從第一章的智能體概論開始，逐步深入。每章都有完整的程式碼範例和練習題。第七章起可跟著實作 HelloAgents 框架。

**學習路徑建議**：
- 初學者：從第一章依序學到最後一章
- 有經驗者：可直接跳到框架實戰（第七章起）或進階知識（第十章起）
