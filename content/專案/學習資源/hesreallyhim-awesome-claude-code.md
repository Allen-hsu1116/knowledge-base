## 是什麼

Awesome Claude Code 是一個精心策展的 Claude Code 資源合集，由 hesreallyhim 維護。它把 Claude Code 生態系中最優質的資源按 19 大分類整理，從入門指南、Anthropic 官方資源，到進階的多 Agent 編排、記憶持久化、安全防護、使用量監控等主題一應俱全。

每個條目都附有 GitHub shields（建立日期、最後 commit、license、stars），讓讀者可以快速評估資源的活躍度和品質。列表強調程式碼品質、安全性和原創性，適合初學者和老手。

列表涵蓋的主題包括：Skills、Plugins、Hooks、Subagents、MCP、Status Lines、Design & UI/UX、Writing & Prose Quality、Creative Media、Infrastructure & DevOps、Security、Multi-Agent Orchestration、Memory & Context Persistence、Usage & Cost Monitoring、Observability、Linting 等。

## 核心特色

- **19 大分類** — 涵蓋 Claude Code 生態系全部面向，從入門到進階
- **GitHub shields** — 每個條目附建立日期/commit/license/stars 徽章
- **Anthropic 官方 + 社區** — 包含官方資源（Agent Skills、Best Practices、Cheatsheet）和社區精華
- **Skills 生態系** — 涵蓋 Skills、Plugins、Hooks、Subagents 完整主題
- **重視品質** — 強調程式碼品質、安全性和原創性
- **持續更新** — 新資源持續加入，legacy 資源保留在 README_ALTERNATIVES

## 怎麼用

### 使用方式

這是一個 awesome-list，直接在 GitHub 上瀏覽即可。找到感興趣的資源後，點擊連結進入對應 repo。

### 安裝資源

大部分收錄的 skills 和 plugins 可透過以下方式安裝：

```bash
# Claude Code plugin
/plugin install <plugin-name>

# Agent Skills (npx skills)
npx skills add <repo-owner>/<repo-name>
```
