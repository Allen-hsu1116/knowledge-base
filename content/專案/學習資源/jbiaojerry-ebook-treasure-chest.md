## 是什麼

這個 repo 彙整電子書連結，並以標籤與 Markdown 分類頁提供瀏覽入口。README 同時連結 GitHub Pages 搜尋頁，可依書名、作者或類別查找。

它屬於一般閱讀資源索引，不是 LLM、RAG 系統或已獲授權的訓練資料集。README 對書籍涵蓋範圍與格式的描述是維護者聲明；本次僅存 README 和 metadata，沒有下載書籍，也未驗證各外部連結的合法性與可用性。

## 核心特色

- 標籤分類：文學、歷史、科普、技術等主題有獨立目錄。

- 即時搜尋：官方 README 指向 GitHub Pages 搜尋介面。

- 多關鍵字查詢：以空格分隔多個關鍵字。

- 瀏覽器搜尋：可在 GitHub 頁面以 Ctrl+F 查找。

- 格式資訊：README 聲稱提供 epub、mobi、azw3 連結，個別項目須查證。

## 怎麼用

### 安裝與準備

使用線上目錄不需安裝。若只要在本機閱讀索引，可取得原始碼；這不是下載書籍的指令。

```bash
git clone https://github.com/jbiaojerry/ebook-treasure-chest.git
cd ebook-treasure-chest
```

### 使用入口

```bash
git status
# 以文字編輯器閱讀 README.md 與 md/ 分類頁
```

### 使用界線

- 優先使用公共領域、作者授權或圖書館提供的合法來源。
- 未查得根目錄 LICENSE，GitHub license metadata 為 null；公開可見不等於允許任意再散布。
- 若用於知識庫，先核對每本書的使用權，再做摘要、切塊與檢索。

## 跟其他方案的關係

| 方案 | 定位 | 選用界線 |
|---|---|---|
| 本專案 | 書籍目錄與搜尋入口 | 不提供授權合法性保證 |
| 個人知識庫 | 整理自己有權使用的素材 | 需要來源、權限與可追溯引用 |
| RAG 應用 | 對已授權文本建立檢索與回答 | 本 repo 不等於現成 RAG pipeline |

本頁收錄的是索引專案本身，不背書其中書籍來源，亦不鏡像電子書內容。
