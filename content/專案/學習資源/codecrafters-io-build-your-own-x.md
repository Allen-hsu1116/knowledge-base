# Build Your Own X

⭐ 504k · 透過從零重建你喜歡的技術來精通程式設計——「我不能創造的東西，我就不理解。」

## 一句話

GitHub 上最大的「從零手做」教學合集，收錄 28 類技術的逐步教學，從 3D 渲染器、資料庫、作業系統到 AI 模型，讓你用 Feynman 的方式學會每一層。

## 快速導航

- 🧠 **LLM** → [[LLM]]（內含 Build Your Own LLM 教學連結）
- 📚 **AI 教學** → [[AI-Tutoring]]（結構化的 AI 學習資源集合）
- 🛠 **程式開發工具** → [[Coding-Agent-CLI]]（AI coding agent 的工具與方法）

## 為什麼重要

程式設計最深層的學習方式不是看別人的程式碼，而是自己從零重建。這個 repo 從 2018 年開始累積，至今涵蓋 3D Renderer、AI Model、BitTorrent Client、Database、Docker、Emulator、Git、Neural Network、Operating System、Programming Language、Search Engine、Shell、Text Editor、Web Browser、Web Server 等 28 大類，每類都有多語言的逐步教學。50 萬顆星不是偶然——它是最接近「程式設計全圖書館」的免費資源。

## 核心概念

- **28 類技術教學** — 從 3D 渲染器到 Web Server，每類獨立成章，用不同語言從零打造
- **多語言覆蓋** — C/C++、Python、JavaScript、Go、Rust、Java 等 10+ 語言的實作教學
- **Feynman 學習法** — "What I cannot create, I do not understand" 貫穿核心理念
- **社群驅動** — 600+ commits、200+ PR，開源社群持續補充新教學
- **關鍵 AI 類別** — AI Model 類別包含 Build Your Own LLM（rasbt/LLMs-from-scratch）、Diffusion Models、RAG for Document Search
