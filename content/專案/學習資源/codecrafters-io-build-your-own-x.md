# Build Your Own X

## 一句話

GitHub 上最大的「從零手做」教學合集，收錄 28 類技術的逐步教學，從 3D 渲染器、資料庫、作業系統到 AI 模型，讓你用 Feynman 的方式學會每一層。

## 快速導航

## 是什麼

Build Your Own X 是 GitHub 上最大的「從零手做」教學合集（50 萬星），由 codecrafters-io 維護。核心精神來自 Feynman 的名言：「What I cannot create, I do not understand」。收錄 28 大類技術的逐步教學，每類都有多個語言的實作指南，涵蓋從 3D Renderer 到 Web Server 的完整技術棧。

### 28 大類教學目錄

3D Renderer、AI Model、Augmented Reality、BitTorrent Client、Blockchain、Bot、Command-Line Tool、Database、Distributed Systems、Docker、Emulator/VM、Front-end Framework、Game、Git、Memory Allocator、Network Stack、Neural Network、Operating System、Physics Engine、Processor、Programming Language、Regex Engine、Search Engine、Shell、Template Engine、Text Editor、Visual Recognition System、Voxel Engine、Web Browser、Web Server

### 關鍵 AI 類別

- **Build Your Own LLM** — 連結到 [[rasbt-LLMs-from-scratch]]（從零打造大語言模型）
- **Diffusion Models** — 用 Python 實作擴散模型影像生成
- **RAG for Document Search** — 用 LangChain 從零打造文件搜尋系統

## 核心特色

- **28 類技術教學** — 從 3D 渲染器到 Web Server，每類獨立成章，用不同語言從零打造
- **多語言覆蓋** — C/C++、Python、JavaScript、Go、Rust、Java、Haskell、Ruby 等 15+ 語言的實作教學
- **Feynman 學習法** — "What I cannot create, I do not understand" 貫穿核心理念
- **社群驅動** — 600+ commits、200+ PR，開源社群持續補充新教學
- **關鍵 AI 類別** — AI Model 類別包含 Build Your Own LLM、Diffusion Models、RAG for Document Search
- **從入門到進階** — 每類教學從簡單到複雜，適合不同水平的學習者
- **程式設計全圖書館** — 50 萬星的免費資源，幾乎涵蓋所有基礎技術的自學路徑

## 怎麼用

```bash
# 複製倉庫
git clone https://github.com/codecrafters-io/build-your-own-x.git
cd build-your-own-x
```

### 直接使用

1. 進入 [GitHub repo](https://github.com/codecrafters-io/build-your-own-x)
2. 選擇想學的技術類別（如 Database、Operating System）
3. 選擇偏好的程式語言
4. 跟著教學一步步從零實作
5. 完成後理解底層原理

### 推薦學習路徑

- **基礎系統**: Shell → Git → Database → Operating System
- **AI/ML 入門**: Neural Network → AI Model (LLM)
- **Web 全栈**: Web Server → Front-end Framework → Web Browser
- **底層理解**: Processor → Operating System → Docker → Emulator/VM

### AI 相關教學

- [LLMs from Scratch](https://github.com/rasbt/LLMs-from-scratch) — 從零打造大語言模型
- [Diffusion Models for Image Generation](https://huggingface.co/learn/diffusion-course/en/unit1/3) — 擴散模型影像生成
- [RAG for Document Search](https://github.com/langchain-ai/rag-from-scratch) — 文件搜尋系統
