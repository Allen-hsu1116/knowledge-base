# OSSU Computer Science

> ⭐206.5k · 完整的免費自學資工系課程，從 Harvard、MIT、Princeton 等頂尖大學精選課程組成

快速導航：[[self-education|自主學習]] · [[freeCodeCamp-freeCodeCamp|freeCodeCamp]] · [[codecrafters-io-build-your-own-x|Build Your Own X]]

## 是什麼

OSSU（Open Source Society University）電腦科學課程是一個完整的自學資工教育路線圖，使用線上免費材料組成。它不只是職業培訓，而是按照大學部資工系的學位要求設計的完整課程，涵蓋所有計算機科學核心概念。

課程來自 Harvard、MIT、Princeton 等世界頂尖大學，按照 CS 2013 課程標準精選。每門課必須定期開課、教學品質高、符合課綱要求。當沒有合適課程時，用書籍補充。

整個課程分為四個階段：Intro CS（入門體驗）、Core CS（前三年核心課程）、Advanced CS（第四年選修）、Final Project（畢業專案）。以每週 20 小時的進度，約 2 年可以完成。

## 核心特色

- **完全免費**：所有或幾乎所有課程材料都免費提供。Coursera 和 edX 提供財務援助。學生可以根據自己的時間和預算決定花多少錢
- **頂尖大學課程**：精選 Harvard、MIT、Princeton 等名校課程，按照 CS 2013 課綱標準組織，確保教育品質與正規大學相當
- **完整四階段架構**：Intro CS → Core CS → Advanced CS → Final Project，對應大學四年課程結構。Core CS 涵蓋程式設計、數學、系統、理論、安全、應用、倫理等必修領域
- **全球社群支援**：活躍的 Discord 社群讓學生互相交流、提問、組隊學習。也可以透過 GitHub issues 參與課程改進
- **彈性學習**：可以獨自學習或組隊，按順序或不按順序。Advanced CS 是選修制，學生可選擇自己想深入的領域

## 怎麼用

```bash
# 不需要安裝，直接造訪官網或 GitHub repo 開始
# 官網：https://cs.ossu.dev
# GitHub：https://github.com/ossu/computer-science
```

1. 造訪 [OSSU CS 官網](https://cs.ossu.dev) 瀏覽完整課程列表
2. 加入 [Discord 社群](https://discord.gg/wuytwK5s9h) 與其他學生交流
3. 從 Intro CS 開始，試試 CS 是否適合自己
4. 使用 [進度試算表](https://docs.google.com/spreadsheets/d/1y2kMsIg9VaHMVmw35x_aH1hpty3V-ZMuV2jA13P_Cgo/copy) 估算完成日期
5. 按順序完成 Core CS，再依興趣選擇 Advanced CS 選修
