# 人生進階指南（up）

> ⭐64.7k · 以真實任務、AI 協作與成果證據串起終身學習的開放內容指南。

## 快速導航

- [[self-education]] — 延伸閱讀與關聯背景。
- [[AI-Tutoring]] — 延伸閱讀與關聯背景。

## 是什麼

這是韓先凱（筆名離譜）持續更新的書稿，由英語學習指南擴展為 AI 時代的終身學習方法。內容涵蓋英語、AI 學習、專案開發、人生復盤與日常實踐，不是模型、Agent 框架或可直接部署的 AI 服務。

它把學習整理成「發現問題、主動學習、與 AI 協作、完成真實任務、保存證據、復盤遷移」的循環。作者刻意區分研究結論、個人經驗與待驗證假設，強調來源查核及最後判斷仍由人承擔。

與 LLM 知識庫的直接關係在於如何使用 AI 學習並交付成果，而不是介紹模型架構。正文採非商業授權，不能將整個倉庫籠統視為 OSI 開源軟體；第三方服務連結也不等於安全或品質背書。

## 核心特色

- **任務導向**：先界定真實問題、能力基線與完成標準，再讓 AI 協助拆解最小任務。

- **成果與證據**：保存筆記、程式、錄音或使用者回饋，而非只累積聊天記錄。

- **實踐工作紙**：提供 learning-state、weekly-review、90-day-cycle 等 Markdown 模板。

- **語言能力基礎**：包含英語聽說讀寫、CEFR 自測及技術閱讀的練習入口。

- **開放閱讀**：README 提供中英文入口與 PDF、EPUB 下載，亦有 GitHub Pages 線上版。

## 怎麼用

### 取得資料與準備環境

```bash
git clone https://github.com/byoungd/up.git
cd up
# 先閱讀指南及學習工作紙，不必安裝模型
less README.md
less docs/templates/learning-state.md
```

### 使用順序與限制

1. 純閱讀可直接使用 https://byoungd.github.io/up/ ，不必架設站台。
2. 上述是取得內容的指令，並非 AI 軟體安裝；本次沒有執行上游程式。
3. 選一項可完成的任務，留下無輔助基線，再用工作紙記錄 AI 協作與獨立完成的成果。
4. 週末以 weekly-review 檢查品質、保持與遷移，避免把生成的答案當成已學會。

## 跟其他方案的關係

以下為依專案定位整理的用途比較，不是效能實測。

| 方案 | 重點 | 適用情境 |
|---|---|---|
| 本專案 | 學習方法與實踐模板 | 需要從資訊收藏走向真實成果 |
| 一般模型 API 文件 | 介面規格與呼叫方式 | 已經明確知道要串接哪個服務 |
| 傳統課程教材 | 特定領域的系統知識 | 需要完整學科脈絡與習題 |
