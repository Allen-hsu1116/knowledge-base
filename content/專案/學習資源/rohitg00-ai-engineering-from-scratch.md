# AI Engineering from Scratch

**⭐ 9,567** | Python | [GitHub](https://github.com/rohitg00/ai-engineering-from-scratch)

從數學到底到 agent swarm 的 AI 工程全方位課程，435 課、20 階段、約 320 小時。

## 課程結構

20 個階段層層堆疊：線性代數 → ML 基礎 → 深度學習 → Vision/NLP/Speech → Transformer → GenAI → LLM from Scratch → LLM Engineering → Tools & Protocols → Agent Engineering → Autonomous Systems → Multi-Agent & Swarms → Infrastructure & Production → Ethics → Capstone。

## 每課六步

Motto → Problem → Concept → **Build It**（手刻原始數學） → **Use It**（同一件事用 PyTorch/sklearn 跑） → **Ship It**（產出 artifact）

每堂課結束都產出一個可用工具：prompt、skill、agent 或 MCP server。

## 四語言

Python、TypeScript、Rust、Julia 四種語言實作。

## 內建 Agent Skills

- `/find-your-level` — 十題測驗定位起始階段，生成個人化學習路徑
- `/check-understanding <phase>` — 階段測驗，八題附回饋
- 搭配 [SkillKit](https://github.com/rohitg00/skillkit) 使用
