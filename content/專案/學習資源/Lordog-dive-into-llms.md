## 是什麼

Dive into LLMs（《動手學大模型》）是由上海交通大學張倬勝老師團隊開發的大模型入門編程實踐教程系列，源自《自然語言處理前沿技術》（NIS8011）和《人工智能安全技術》（NIS3353）課程講義。教程屬公益性質、完全免費，旨在通過簡單實踐幫助學生快速入門大模型，更好地開展課程設計或學術研究。

教程覆蓋 11 個核心主題：微調與部署、提示學習與思維鏈、知識編輯、數學推理（蒸餾迷你 R1）、模型水印、越獄攻擊、大模型隱寫、多模態模型、GUI 智能體、智能體安全、RLHF 安全對齊。每個主題都包含課件、教程和可執行腳本。

此外，教程還聯合華為昇騰推出了《大模型開發全流程》系列課程，基於昇騰基礎軟硬件開發，覆蓋 PPT、實驗手冊和視頻，分為初級、中級、高級三個層次，面向不同的大模型實踐需求。

## 核心特色

- **11 大主題完整覆蓋** — 從微調部署到安全對齊，涵蓋大模型開發全生命週期，每個主題都有課件、教程和腳本三件套
- **公益免費教育** — 上海交通大學課程講義拓展而來，完全免費開源，降低大模型學習門檻
- **安全主題深入** — 特別涵蓋越獄攻擊、模型水印、大模型隱寫、智能體安全等前沿安全議題，少見的安全導向 LLM 教程
- **蒸餾迷你 R1** — 包含數學推理主題，教你如何快速蒸餾一個迷你 R1 模型，跟隨前沿趨勢
- **華為昇騰國產化** — 聯合華為推出基於昇騰平台的全流程開發課程，覆蓋初級到高級
- **GUI Agent 實作** — 包含 GUI 智能體主題，教你讓 AI Agent 替你點外賣、回消息、購物比價

## 怎麼用

### 線上瀏覽

直接到 GitHub repo 瀏覽教程目錄，每個主題對應一個文件夾，包含課件、教程和腳本。

```bash
git clone https://github.com/Lordog/dive-into-llms.git
cd dive-into-llms
```

### 教程結構

每個主題包含三個部分：
- **課件 (PPT)** — 理論講解
- **教程** — 詳細步驟說明
- **腳本** — 可執行的編程實踐

### 昇騰全流程課程

前往昇騰社區探索《大模型開發全流程》系列課程，包含 PPT、實驗手冊和視頻。
