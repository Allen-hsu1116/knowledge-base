## 是什麼

阮一峰的科技愛好者周刊是以 GitHub 儲存 Markdown 內容的長期策展專案。README 說明每週五發布，並以年份、月份與期數索引文章，讀者可以直接從目錄進入各期內容。

它不是 LLM 框架，也不提供模型執行 API；與本知識庫的關聯是 AI 資訊發現與自主學習。近期目錄包含 AI 機制、快取、記憶與 Token 費用等題目，但這些標題不代表本文已核查各期文章的全部技術論述。

## 核心特色

- **長期時間索引**：README 依年份與月份整理各期期數與連結。
- **每週策展**：主題涵蓋科技、軟體資源與開發者職涯，而非只收 AI 新聞。
- **可離線保存**：每期內容位於 docs/ 的 Markdown 文件，可用 Git 保留閱讀版本。
- **社群投稿**：README 明確以 Issues 接受文章、軟體與資源投稿。
- **就業資訊入口**：README 另連結「誰在招人」討論串，與技術正文分開。

## 怎麼用

### 安裝與取得

閱讀不需要安裝服務；以下是可選的本地內容取得方式，需要 Git。

```bash
git clone --depth 1 https://github.com/ruanyf/weekly.git
cd weekly
# 用編輯器開啟 README.md，再依目錄閱讀 docs/issue-*.md
```

### 建議操作流程

1. 先看 README 的近期目錄，挑選與當前學習目標相關的一期。
2. 沿原文連結追溯第一手來源，再把已確認的概念整理進自己的筆記。
3. 更新離線版本前先確認沒有未提交的個人筆記，避免把筆記混入來源倉庫。

### 使用限制與核查邊界

- **來源邊界**：周刊是發現入口，不取代官方文件或論文。
- **授權邊界**：GitHub metadata 未標示 license，根目錄也未列出授權檔；公開可讀不等於可任意再散布。

以下是用途與分層比較，不是實测效能排行。
