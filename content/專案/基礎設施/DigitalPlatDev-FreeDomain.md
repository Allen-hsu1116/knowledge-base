# DigitalPlat FreeDomain

> ⭐167k+ · 完全免費的域名註冊服務，讓每個人都能擁有自己的數位身份

快速導航：[[free-domain|免費域名]] · [[self-hosted|自架服務]] · DNS · [[open-source-business|開源商業模式]]

## 是什麼

DigitalPlat FreeDomain 是一個由 DigitalPlat Foundation 維護的非營利免費域名註冊服務。提供 `.DPDNS.ORG`、`.US.KG`、`.QZZ.IO`、`.XX.KG`、`.QD.JE` 等多種免費頂級網域，可搭配 Cloudflare、FreeDNS 等第三方 DNS 服務自行託管。已有超過 50 萬個域名完成註冊。

## 核心特色

- 🌐 **免費域名**：多種免費 domain extension 可選，無須付費
- 🏠 **自主 DNS 託管**：支援 Cloudflare、FreeDNS by Afraid.org、Hostry 等第三方 DNS
- 📊 **大規模使用**：已超過 50 萬個域名註冊
- 💡 **起源故事**：創辦人 15 歲時的 DNS 實驗，逐步發展成服務數十萬用戶的平台
- 🤝 **非營利性質**：由 DigitalPlat Foundation 維護，致力於讓網路更開放
- 🔒 **安全回應**：有完整的使用者回報濫用機制（abusereport@digitalplat.org）

## 怎麼用

```bash
# 1. 前往註冊面板
# https://dash.domain.digitalplat.org/

# 2. 選擇域名 extension
# .DPDNS.ORG / .US.KG / .QZZ.IO / .XX.KG / .QD.JE

# 3. 註冊域名並設定 DNS
# 可搭配 Cloudflare、FreeDNS、Hostry 等 DNS 服務

# 4. 查看教學文件
# https://docs.digitalplat.org/
```

完全免費，無需信用卡。註冊後在 DNS 服務商設定指向即可上線。
