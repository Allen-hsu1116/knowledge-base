# the-book-of-secret-knowledge

- **Repo**: [trimstray/the-book-of-secret-knowledge](https://github.com/trimstray/the-book-of-secret-knowledge)
- **Stars**: 222k ⭐
- **Language**: Markdown
- **Added**: 2026-05-22

## 一句話

系統管理、DevOps、資安研究者的瑞士刀——CLI/GUI/Web 工具、cheatsheet、one-liner 大全集。

## 快速導航
- ⚡ [[pentesting]] · [[Coding-Agent-CLI]]

## 是什麼

一個 222k star 的超大型知識彙整庫，涵蓋 16 個主題章節：CLI 工具（shell、編輯器、網路診斷）、GUI 工具、Web 工具、容器編排、滲透測試、shell one-liners 等。每個章節按類別整理數十到上百個工具連結與簡述，是系統管理與資安從業者的每日參考手冊。Markdown 格式方便搜尋與整合到自己的知識庫。

核心受眾是 System/Network administrators、DevOps、Pentesters、Security Researchers——但實際上任何人都能找到實用內容。

## 核心特色

- **222k star 社群驗證** — 品質經過大量 PR 篩選，只收錄 good quality stuff
- **16 個主題章節** — CLI Tools、GUI Tools、Web Tools、Systems/Services、Networks、Containers/Orchestration、Manuals/Howtos、Hacking/Penetration Testing、Shell One-liners、Shell Tricks 等
- **純 Markdown 格式** — 容易搜尋、整合到知識庫、格式統一
- **持續更新** — 社群貢獻活躍，定期新增內容
- **實用導向** — 每個工具只列名稱+一句描述，快速掃描定位

主要章節概覽：
- **CLI Tools** — Shells（Bash、Zsh）、Shell plugins（fzf、zsh-autosuggestions）、Managers（tmux、ranger）、Network（nmap、masscan、Wireshark）、Security（SELinux、AppArmor）、System Diagnostics（strace、perf、FlameGraph）
- **GUI Tools** — 網路分析、終端工具、資安工具的 GUI 版本
- **Web Tools** — 線上分析、DNS lookup、SSL 檢查等
- **Hacking/Penetration Testing** — 滲透測試工具大全，涵蓋偵查、漏洞利用、後滲透
- **Shell One-liners** — 常用 shell 單行指令，系統管理日常必備
- **Containers/Orchestration** — Docker、K8s 等容器相關工具

## 怎麼用

- 直接在 GitHub 上閱讀和搜尋
- Clone 到本地做為離線參考手冊：
  ```bash
  git clone https://github.com/trimstray/the-book-of-secret-knowledge.git
  ```
- 整合到自己的知識庫（Markdown 格式最適合搜尋和引用）
- 遇到問題時，先查相關章節再找特定工具的文件
- 用 GitHub 搜尋功能快速定位特定工具

## 與我們的知識庫方法論的關係

the-book-of-secret-knowledge 的純 Markdown 格式跟我們的 [[llm-knowledge-base]] 方法論高度契合：
- Markdown 格式方便 LLM 直接引用和檢索
- 每個工具只列名稱+一句描述，正好適合 LLM 的快速定位需求
- 可以做為知識庫 raw 素材，經過編譯後融入 wiki 頁面
