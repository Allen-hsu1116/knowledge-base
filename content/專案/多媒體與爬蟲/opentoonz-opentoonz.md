# OpenToonz — 開源 2D 動畫創作軟體

> ⭐6.3k · 基於吉卜力工作室客製化的 Toonz 衍生開源 2D 動畫軟體，專業級免費替代方案

## 是什麼

OpenToonz 是一款開源 2D 動畫創作軟體，源自義大利 Digital Video 開發的 Toonz，經 Studio Ghibli 多年實戰客製化後，由 DWANGO 開源釋出。它是專業級 2D 動畫製作的免費替代方案，支援 Windows、macOS、Linux、BSD 等多平台。

## 核心特色

- **吉卜力實戰驗證** — Studio Ghibli 多年客製化的產業級工具
- **跨平台** — Windows、macOS、Linux、BSD 全支援
- **專業級功能** — 矢量和點陣圖動畫、骨骼動畫、粒子效果、色彩設計等
- **完全開源** — Modified BSD License，免費使用
- **開放架構** — 支援插件擴展和腳本自訂

## 怎麼用

```bash
# 從 GitHub 下載安裝包
# https://github.com/opentoonz/opentoonz/releases

# 或從原始碼建置
git clone https://github.com/opentoonz/opentoonz.git
cd opentoonz
# 詳見各平台建置指南：toonz/sources/README.md

# macOS 使用者可透過 Homebrew 安裝依賴後編譯
# Windows 使用者直接下載 .exe 安裝包
```

## 跟其他方案的關係

| 方案 | 定位 | 2D 動畫 | 3D | 開源 | 授權 |
|------|------|---------|-----|------|------|
| **OpenToonz** | 專業 2D 動畫 | ✅ | ❌ | ✅ | Modified BSD |
| **[[Blender]]** | 3D 建模動畫 | 部分 | ✅ | ✅ | GPL |
| **[[Synfig Studio]]** | 2D 向量動畫 | ✅ | ❌ | ✅ | GPL |

- OpenToonz 在 [[generative-AI]] 時代仍定位為專業 2D 動畫創作核心工具
- **vs Blender**：OpenToonz 專注 2D 動畫，Blender 專注 3D；兩者互補
- **vs Synfig Studio**：OpenToonz 有吉卜力實戰驗證，功能更完整；Synfig 更輕量專注向量動畫
