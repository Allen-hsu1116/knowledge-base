# OpenToonz — 開源 2D 動畫創作軟體

**⭐ 6,347** | C++ | [GitHub](https://github.com/opentoonz/opentoonz)

基於吉卜力工作室客製化的 Toonz 衍生開源 2D 動畫軟體。

## 背景

源自義大利 Digital Video 開發的 Toonz，經 Studio Ghibli 多年實戰客製化後，由 DWANGO 開源釋出。是專業級 2D 動畫製作的免費替代方案。

## 支援平台

Windows、macOS、Linux、BSD
