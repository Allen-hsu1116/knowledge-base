# VoxCPM

> ⭐31007 · Tokenizer-Free TTS，2B 模型支援 30 語言，48kHz 音質，語音設計 + 可控克隆 + 完美還原克隆

## 是什麼

VoxCPM（最新版 VoxCPM2）是 OpenBMB 推出的**無分詞器（tokenizer-free）文字轉語音系統**。它直接透過端到端**擴散自回歸架構**生成連續語音表示，跳過離散分詞化，實現高度自然且富有表現力的合成。

VoxCPM2 是最新主版本——**2B 參數**，用 **200 萬+ 小時**多語言語音數據訓練，支援 **30 種語言**，基於 MiniCPM-4 主幹。支援 48kHz 錄音室品質音訊輸出，RTF 低至 ~0.13（搭配 Nano-vLLM）。

## 核心特色

- 🌍 **30 語言多語言** — 阿拉伯語、中文、英文、日文、韓文等 30 種語言直接合成，無需語言標籤
- 🎨 **語音設計（Voice Design）** — 用自然語言描述（性別、年齡、語調、情感、節奏）創造全新語音，不需參考音訊
- 🎛️ **可控克隆（Controllable Cloning）** — 從短參考音檔克隆音色，可加風格指引調整情感和節奏
- 🎙️ **完美還原克隆（Ultimate Cloning）** — 提供參考音檔 + 逐字稿，模型從參考處無縫接續，保留所有聲音細節
- 🔊 **48kHz 高音質** — 透過 AudioVAE V2 非對稱編解碼，內建超解析度，不需外部升採樣器
- ⚡ **即時串流** — RTX 4090 上 RTF ~0.3，搭配 Nano-vLLM 降至 ~0.13
- 📜 **完全開源商用** — Apache-2.0，權重和程式碼免費商用
- 🧠 **上下文感知合成** — 自動從文字內容推斷適當韻律和表現力

## 怎麼用

### 安裝

```bash
pip install voxcpm
```

> 需要 Python ≥ 3.10, PyTorch ≥ 2.5.0, CUDA ≥ 12.0

### 文字轉語音

```python
from voxcpm import VoxCPM
import soundfile as sf

model = VoxCPM.from_pretrained("openbmb/VoxCPM2", load_denoiser=False)
wav = model.generate(
    text="VoxCPM2 is the current recommended release.",
    cfg_value=2.0,
    inference_timesteps=10,
)
sf.write("demo.wav", wav, model.tts_model.sample_rate)
```

### 語音設計（無需參考音檔）

```python
wav = model.generate(
    text="(A young woman, gentle and sweet voice)Hello, welcome to VoxCPM2!",
    cfg_value=2.0,
    inference_timesteps=10,
)
```

### 語音克隆

```python
wav = model.generate(
    text="This is a cloned voice generated by VoxCPM2.",
    reference_wav_path="path/to/voice.wav",
)
```

### 串流 API

```python
chunks = []
for chunk in model.generate_streaming(text="Streaming TTS is easy!"):
    chunks.append(chunk)
wav = np.concatenate(chunks)
```

### 生產部署（vLLM-Omni）

```bash
vllm serve openbmb/VoxCPM2 --omni --port 8000
# OpenAI 相容 API
curl http://localhost:8000/v1/audio/speech \
  -H "Content-Type: application/json" \
  -d '{"model":"openbmb/VoxCPM2","input":"Hello!","voice":"default"}' \
  --output out.wav
```

## 跟其他方案的關係

| 模型 | 參數 | 開源 | WER-EN | SIM-EN | 特色 |
|------|------|------|--------|--------|------|
| **VoxCPM2** | 2B | ✅ | 1.84% | 75.3% | 30 語言、Voice Design、48kHz |
| FishAudio S2 | 4B | ✅ | 0.99% | — | WER 最低但參數最大 |
| Qwen3-TTS | 1.7B | ✅ | 1.23% | 71.7% | Qwen 生態整合 |
| CosyVoice3 | 1.5B | ❌ | 2.02% | 71.8% | 阿里閉源 |
| F5-TTS | 0.3B | ✅ | 2.00% | 67.0% | 輕量級 |
| ElevenLabs | — | ❌ | — | — | 商業服務，多語言 WER 領先 |

**關鍵差異**：VoxCPM2 在開源 TTS 中 SIM（音色相似度）領先，30 語言 + Voice Design + 完全商用免費是最大賣點。
