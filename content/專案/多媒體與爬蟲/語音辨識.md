# 語音辨識 (Speech Recognition)

> 將語音轉為文字（ASR）和將文字轉為語音（TTS）的技術。是 AI 多模態應用的關鍵組件。

## 是什麼

語音辨識是將語音訊號轉換為文字（ASR，Automatic Speech Recognition）的技術，語音合成則是反向將文字轉為語音（TTS，Text-to-Speech）。兩者合稱語音技術，是 AI 多模態應用的關鍵組件——讓機器能「聽」和「說」。

## 語音技術分類

| 技術 | 方向 | 應用 |
|------|------|------|
| ASR（語音辨識） | 語音 → 文字 | 轉錄、語音指令 |
| TTS（語音合成） | 文字 → 語音 | 語音助手、有聲書 |
| STT + 翻譯 | 語音 → 另一語言文字 | 即時翻譯 |
| 語音克隆 | 少量樣本 → 任意文字語音 | 個人化語音 |

## 核心特色

### ASR 核心
- **多語言支援**：Whisper 支援 100+ 語言
- **魯棒性**：噪音環境、口音、低音質下的辨識能力
- **即時串流**：低延遲的串流辨識
- **強制對齊**：精確到詞級別的時間戳

### TTS 核心
- **語音克隆**：少量樣本複製特定說話人聲音
- **多語言合成**：單一模型支援多種語言
- **情感控制**：調整語速、語調、情感
- **即時串流**：低延遲的語音生成

## 怎麼用

### Whisper（語音辨識）

```bash
pip install -U openai-whisper
```

```python
import whisper

model = whisper.load_model("base")
result = model.transcribe("audio.mp3")
print(result["text"])  # 辨識結果
print(result["language"])  # 偵測語言
```

CLI 也能用：
```bash
whisper audio.mp3 --model base --language zh
```

### edge-tts（語音合成）

```bash
pip install edge-tts
```

```python
import edge_tts

communicate = edge_tts.Communicate("你好世界", "zh-TW-HsiaoChenNeural")
await communicate.save("output.mp3")
```
