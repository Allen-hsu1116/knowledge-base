## 是什麼

**Awesome LLM Apps** 是一個包含 100+ 個可直接運行的 LLM 應用模板的開源集合。不同於一般的 awesome list 只是連結彙整，這裡的每個模板都是原創的手工打造代碼，經過端到端測試，可以 clone 下來直接跑。

模板涵蓋了現代 AI 技術栈的各個層面：AI Agents、Multi-agent Teams、MCP Agents、Voice AI Agents、RAG、Agent Skills、Fine-tuning 等。支援多種 LLM 供應商（Claude、Gemini、GPT、Llama、Qwen、xAI），只需修改設定即可切換。

## 核心特色

- **🛠️ 手工打造，非策展** — 每個模板都是原創代碼，經過完整測試
- **🏃 三指令即可運行** — 不會遇到壞掉的依賴或模糊的鷹架代碼
- **🧠 涵蓋現代 AI 技術栈** — Agent、Multi-agent、RAG、Voice、MCP、Skills、Fine-tuning
- **🌐 供應商無關** — 一個設定檔切換 Claude/Gemini/GPT/Llama/Qwen/xAI
- **📚 每個模板有免費教學** — Unwind AI 提供步驟式教學
- **💸 Apache 2.0 開源** — 可自由 fork、商業使用

## 怎麼用

```bash
# 克隆專案
git clone https://github.com/Shubhamsaboo/awesome-llm-apps.git
cd awesome-llm-apps

# 進入想跑的模板目錄
cd ai_agents/1_ai_news_agent

# 安裝依賴
pip install -r requirements.txt

# 設定 API key
export OPENAI_API_KEY=your_key

# 運行
python ai_news_agent.py
```
